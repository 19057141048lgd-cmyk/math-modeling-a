## 做法

三个小问共用一套框架：两级粗化（含内存感知聚簇），通信感知列表调度（另有 BLC 优先级候选），代理模型（算子级调度模型 + 精确 spill 模型）选优，需要时再交官方评估器复核。差别只在代价模型和方案怎么构造。

全量 100 个用例、只用模型选优时（v2），5 核平均加速比是：问题1 **3.817**，问题2 **4.421**，问题3 **4.506**（v1 为 3.76 / 4.32 / 4.43）。这是模型选优后的官方成绩，不是候选中经官方验证的最优；单核加速比按题目定义为 1；随核数单调不增是靠兜底比较保证的。口径和分项都在设计文档第 0 节、第 7.4 节，原始数字以 `A题方案/results_all/summary.csv` 为准。

## 怎么跑

在 `A题方案` 目录下执行。Python 3.10 及以上，求解只用标准库，画图需要 matplotlib。官方附件由 `solver/config.py` 自动定位。

```powershell
python -m solver.solve case_050 --cores 4 --problem 2 --verify 2 -o results/case_050_p2_n4.json
python -m solver.run_batch --cases all --verify 0 --workers 8 --out results_all
python -m solver.dev_spill results_all
```

`run_batch` 中断后用同一条命令重跑，只会补未完成的用例；求解代码、官方评估程序或用例文件变了的用例会自动重算，加 `--force` 则全部重算。其余命令、参数和论文分工在设计文档第 9、10 节。
